# go-arcade-toolbox

`go-arcade-toolbox` is a from-zero rewrite of [go-wallet-toolbox](https://github.com/bsv-blockchain/go-wallet-toolbox): an arcade-only, BRC-100-compliant BSV wallet toolbox designed for high throughput (1000+ TPS), with pluggable UTXO storage backends (PostgreSQL, SQLite, Aerospike). Status: under active development. The public API is being kept compatible with go-wallet-toolbox method signatures to ease migration.

Documentation will land in [`docs/`](docs/) as the project develops.
